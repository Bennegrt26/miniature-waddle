Import your real units with Termux

Brings in each unit's room name, model, MAC address and wired/wireless status. eero doesn't store where units physically are, so positions stay as you set them on the map. Units already on the map keep their position when the name or MAC matches.

Steps
  1. Install Termux from F-Droid.
  2. In Termux, run termux-setup-storage once and tap Allow, so the file can be saved to Downloads.
  3. Copy the command below, paste it into Termux and follow the prompts. eero sends you a login code.
  4. Choose the saved file below, or paste the JSON it prints.

If the install stops with an error about pydantic-core, run pkg install rust and try again (the build can take a while). The same command also works on a computer with Python 3.12 or newer. It uses eero-api, an unofficial package that keeps a login token on the device.

Termux command 
pkg update -y && pkg install python -y && pip install eero-api==8.4.1 && python -c '
import asyncio, json

from eero import EeroClient

async def main():
    async with EeroClient() as c:
        if not c.is_authenticated:
            await c.login(input("eero email or phone: "))
            await c.verify(input("Verification code: "))
        resp = await c.get_eeros()
        eeros = resp.get("data") or []
        if not eeros:
            print("No eero units found on this account.")
            return
        print("Fields:", sorted(eeros[0].keys()))
        out = [{
            "name": e.get("location") or "eero",
            "model": e.get("model") or "",
            "gateway": bool(e.get("gateway")),
            "wired": bool(e.get("wired") or e.get("is_wired") or str(e.get("connection_type") or "").lower() == "wired"),
            "status": e.get("status") or "green",
            "mac": e.get("mac_address") or e.get("mac") or e.get("serial") or ""
        } for e in eeros]
        js = json.dumps(out, indent=2)
        print("\n--- COPY JSON BELOW ---\n" + js + "\n-----------------------")
        dl = "/sdcard/Download/eero_nodes.json"
        try:
            with open(dl, "w") as f:
                f.write(js)
            print("Saved to " + dl)
        except OSError:
            with open("eero_nodes.json", "w") as f:
                f.write(js)
            print("Saved to ./eero_nodes.json")

asyncio.run(main())
'
